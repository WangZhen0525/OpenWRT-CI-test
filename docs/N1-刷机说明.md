# 斐讯 N1 固件刷机说明

> 适用于本仓库 `N1-ALL` / `WRT-TEST (AML-N1)` 构建产出的斐讯 N1 固件。
>
> 固件基于 [coolsnowwolf/lede](https://github.com/coolsnowwolf/lede) 的 **amlogic** 平台构建，
> 设备：`phicomm_n1`（Amlogic Meson GXL / S905D）。

---

## 一、固件说明

- 文件名形如：`amlogic-mesongx-phicomm_n1-squashfs-sysupgrade-<源码>-<分支>-<日期>.img.gz`
- 这是一个 **完整的磁盘镜像**（解压后为 `.img`），包含：
  - FAT 启动分区：u-boot 覆盖层（`u-boot.emmc`）、内核、设备树、启动脚本
  - ext4/squashfs 根文件系统（rootfs 约 256MB）
- 同一份镜像既可以 **U盘启动**，也可以 **写入 eMMC 正式使用**。
- N1 内置博通 AP6255 双频无线（2.4G/5G）与千兆有线网口。

### 固件默认信息

| 项目 | 默认值 |
| --- | --- |
| 管理地址 | http://192.168.10.1 |
| 登录账号 | `root`（首次登录会提示设置密码） |
| 无线 SSID / 密码 | `OWRT` / `12345678`（需在 LuCI 无线页面手动启用） |
| 主机名 | `OWRT` |

---

## 二、准备工作

1. 一个 **8GB 或更大** 的 U盘（将用于启动/安装）。
2. 电脑上的写盘工具（任选其一）：
   - [balenaEtcher](https://etcher.balena.io/)（推荐，跨平台）
   - [Rufus](https://rufus.ie/)（Windows）
   - [Win32DiskImager](https://sourceforge.net/projects/win32diskimager/)（Windows）
   - Linux/macOS 命令行 `dd`
3. 网线一根（调试时电脑直连 N1 网口，或接入同一局域网）。

---

## 三、写入 U盘

> **重要**：`.img.gz` 必须先解压成 `.img` 再写盘，**不要**把 `.gz` 直接写进 U盘。

1. 解压固件：`xxx.img.gz` → `xxx.img`（Windows 可用 7-Zip / 解压工具；Linux 用 `gzip -d xxx.img.gz`）。
2. 打开写盘工具，选择解压后的 `.img` 文件，目标磁盘选择 **U盘**，点击开始写入。
3. 写入完成后安全弹出 U盘。

Linux `dd` 示例（**请务必确认 `/dev/sdX` 是你的 U盘**）：

```bash
gzip -d xxx.img.gz
sudo dd if=xxx.img of=/dev/sdX bs=4M conv=fsync status=progress
```

## 四、从 U盘启动（首次刷机 / 体验）

### 情况 A：N1 还是原厂（斐讯）系统

1. N1 连接网络并通电开机，进入原厂系统的 **设置 → 远程调试**，打开 **ADB 调试**（部分版本需要登录斐讯账号）。
2. 电脑安装 adb 工具（Android SDK platform-tools），并和 N1 处于同一局域网：

   ```bash
   adb connect <N1的IP地址>
   adb shell reboot update
   ```

3. 在输入命令前，先把写好的 U盘插入 N1（建议插在 **靠近 HDMI 接口的 USB 口**），随后 N1 会自动从 U盘引导。
4. 如果 ADB 方式无法进入 U盘启动（高版本 bootloader 限制），需要先 **降级 bootloader**：
   - 下载 N1 降级包（V2.19 / V2.22 对应的降级镜像），通过 USB 双公头线 + 刷机工具（如 USB_Burning_Tool）刷入，再重复上述步骤。

### 情况 B：N1 已刷过其他 OpenWrt / Armbian 等第三方系统

直接插入写好的 U盘并重启即可，第三方系统的 u-boot 通常会自动从 U盘引导。

### 启动成功后的验证

- 电脑用网线连接 N1 网口，浏览器访问 **http://192.168.10.1**
- 或 SSH 登录：`ssh root@192.168.10.1`（默认无密码，首次登录设置）
- 看到 OpenWrt 管理界面即表示 U盘启动成功。

---

## 五、安装到 eMMC（正式使用，推荐）

U盘启动成功后，可把固件写入 N1 内置 eMMC，之后拔掉 U盘也能开机。

1. SSH 登录 U盘系统：

   ```bash
   ssh root@192.168.10.1
   ```

2. 运行官方安装脚本：

   ```bash
   /root/install-to-emmc.sh
   ```

3. 按提示输入 `y` 确认。脚本会自动：
   - 识别 eMMC（大于 2.8GB 的非启动 mmcblk 设备）
   - 重新分区 eMMC（boot + rootfs + 保留区）
   - 把当前 U盘系统的启动分区与根分区拷贝到 eMMC
4. 看到 `All Done!` 后执行 `poweroff`，**拔掉 U盘**，重新上电，N1 将从 eMMC 启动。

> 手动方式（不推荐，容易选错设备）：把镜像传到 N1 后
> `dd if=/tmp/xxx.img of=/dev/mmcblk1 bs=4M conv=fsync`，
> 写入前务必用 `lsblk` 确认 eMMC 的设备名。

---

## 六、扩容根分区（可选）

默认 rootfs 分区约 256MB，装 Docker 或大量插件后可能不够用。

- 登录 LuCI → **磁盘扩容**（partexp）插件，选择 eMMC 根分区一键扩容；
- 或使用 **磁盘管理**（diskman）查看/调整分区。

---

## 七、升级固件

- 同设备小版本升级：LuCI → **系统 → 备份/升级**，上传新的 `*.img.gz` 直接刷写（保留配置）。
- 跨版本或分区结构变化：建议重新走一遍 **U盘启动 → install-to-emmc.sh** 流程，避免分区布局不匹配。

---

## 八、恢复原厂 / 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 一直无法从 U盘启动 | 先降级 bootloader（见第四节），或换个 U盘/USB 口/供电（建议 5V/2A 以上电源） |
| 刷完 eMMC 无法启动 | 重新 U盘启动，再执行一次 `install-to-emmc.sh` |
| 想恢复原厂系统 | 使用 USB 双公头线 + USB_Burning_Tool 线刷原厂镜像（注意会清空所有数据） |
| 忘记登录密码 | U盘启动后执行 `passwd` 重设；或 LuCI 恢复出厂 |
| WiFi 找不到 | 到 LuCI **无线** 页面手动启用 `radio0`（N1 内置 AP6255 需要固件驱动，本固件已包含） |

---

## 九、风险提示

- 刷机有变砖风险，请确保电源稳定、操作无误；重要数据请提前备份。
- 写盘 / dd 操作前务必核对目标设备，选错会清空其他磁盘数据。
